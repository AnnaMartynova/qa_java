# qa_java
QA Java Project

Был реализован Maven-проект на Java с тестированием зоосистемы (Feline, Cat, Lion). Выполнена инъекция зависимости для класса Lion (убрана прямая зависимость от Feline). Написаны тесты с использованием Mockito (моки для Feline) и параметризацией (JUnit @ParameterizedTest). Jacoco показывает 100% покрытие классов Feline, Cat и Lion. Все тесты вынесены в соответствующие классы, параметризованные тесты — в отдельные классы.
